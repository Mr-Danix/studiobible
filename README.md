## 📖 About

The **Ultimate Pro Studio Bible** is a comprehensive, single-page web application that serves as the ultimate reference guide for music producers, audio engineers, and sound designers. Built with a stunning neon-glassmorphism aesthetic, it combines **beautiful design** with **deep technical content** covering everything from music theory fundamentals to professional mixing workflows.

> *"This isn't just a guide. It's the bible."*

---

## ✨ Features

### 🎨 Visual Experience
- 🌊 **Neon Glassmorphism UI** — Modern, futuristic design with animated gradient borders
- 🎧 **Interactive Studio Backgrounds** — Floating SVG headphones, speakers, and vinyl records
- 📊 **Scroll-Reactive Physics** — Background elements respond to scroll speed (vinyl spins faster, speakers pulse)
- 🎚️ **Dancing EQ Visualizers** — Animated equalizer bars throughout the interface
- 🌙 **Dark/Light Mode Toggle** — Seamless theme switching with smooth transitions
- ✨ **Floating Particle System** — Canvas-based ambient particle background
- 🎯 **3D Tilt Effects** — Cards respond to mouse movement with perspective transforms

### 🔐 Authentication System
- 📝 **Secure Registration** — Full name, email, password with confirmation
- 🔑 **Protected Login** — Validates against registered credentials
- 🛡️ **Session Management** — Uses `localStorage` + `sessionStorage` for persistence
- ⚠️ **Smart Error Messages** — Specific feedback (unregistered email vs. wrong password)
- 🎬 **Cinematic Loading Screen** — Spinning vinyl + waveform progress + rotating studio messages

### 🎵 Content Coverage
- 🎼 **Music Theory** — Scales, chords, modes, intervals, progressions
- 🥁 **Rhythm & Timing** — Time signatures, subdivisions, polyrhythms
- 🔌 **Sound Systems** — Signal chain, cables, gain staging, phase
- 🎛️ **REAPER Workflows** — Setup, mixing, automation, rendering
- 📊 **Complete EQ Reference** — 4-band settings for 15+ instruments
- 💡 **Pro Tips** — Gain staging, mono checks, reference tracks

### 🔍 Smart Search
- ⚡ **Real-time Filtering** — Instantly finds matches across all content
- 🎨 **Highlight Matches** — Purple highlights on found terms
- 📂 **Auto-Expand** — Opens "See More" sections when searching
- 🧹 **Clean Reset** — Returns to collapsed state when search is cleared
